# Márczius Tizenötödike — rendezői forgatókönyv

Nyilvános, megosztható változata a *Márczius Tizenötödike* rendezői forgatókönyvnek:
egy 5 perces rövidfilm terve Pest–Buda 1848. március 15-i napjáról (9 jelenet, 46 beállítás).

A történelmi szereplők, helyszínek, dialógusok és a referenciaállomány korabeli, forrásolt ábrázolásokon alapulnak.

**Oldal:** nyisd meg az [index.html](index.html) fájlt, vagy a GitHub Pages címet.

A `img/` mappa a forgatókönyv referenciaképeit tartalmazza (dagerrotípia, litográfia, korabeli metszetek és dokumentumok). A források és a pontos képaláírások a forgatókönyvben szerepelnek.
